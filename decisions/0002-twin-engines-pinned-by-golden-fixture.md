# 0002 — Twin deterministic engines, pinned by a golden fixture

**Date:** 2026-07-05 · **Status:** accepted

The cost-model engine exists twice: Python
(`pipelines/src/pipelines/costmodel/engine.py`) for pipelines and CI, and
TypeScript (`web/src/lib/engine.ts`) so the Ledger's sliders (P2) recompute
in the browser with zero backend.

Duplication is a real risk; it is contained by `models/tests/golden.json`,
generated by the Python engine and asserted against by both test suites. CI
additionally regenerates the fixture and fails on drift, so neither engine can
change output alone. The expression language is deliberately tiny (numbers,
identifiers, `+ - * /`, parentheses) to keep two ~100-line implementations
verifiably identical — if a model needs more, decompose the model, don't grow
the language.
